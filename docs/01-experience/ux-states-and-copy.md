# 화면 상태와 카피

[문서 허브](../README.md) · [PRD](../00-product/prd.md) · [사용자 여정](user-journey.md) · [보안 설계](../06-trust/security-design.md)

이 문서는 사용자가 보는 주요 화면, 상태 전이와 공식 한국어 문구의 의미를 정의한다. 실제 UI 문장은 접근성·레이아웃 검토에서 길이를 다듬을 수 있지만 목적·외부 전송·비저장·대체 수단과 안전 한계는 삭제할 수 없다.

## 1. 공통 상태 모델

모든 비동기 화면은 다음 상태를 구분한다.

| 상태 | 요구사항 |
|---|---|
| `idle` | 다음 행동과 현재 조건이 분명하다. |
| `loading` | 100ms 이내 진행 상태와 취소 가능 여부를 알린다. |
| `success` | 무엇이 완료됐고 다음 행동이 무엇인지 알린다. |
| `partial` | 사용 가능한 결과와 실패한 부분을 분리한다. |
| `empty` | 데이터 범위와 제거 이유를 설명하고 회복 행동을 제공한다. |
| `error` | 가짜 결과 없이 재시도·대체 경로를 제공한다. |
| `stale` | 기준 시각과 신뢰 저하 또는 차단 이유를 표시한다. |
| `confirming` | 삭제·외부 전송처럼 되돌리기 어려운 범위를 명시한다. |

## 2. 시작과 로그인

### 기본

**제목:** 먹고 싶은 빵을 말해 주세요

**설명:** 맛과 식감, 메뉴와 오늘 갈 수 있는 범위를 말하면 서울의 베이커리 후보를 찾아드려요.

**버튼:** 카카오로 시작하기

**안전 고지:** 빵찾깅은 빵집 추천 서비스입니다. 재료·알레르기·교차접촉 정보는 검증하지 않으며 안전을 보장하지 않습니다. 주문하거나 방문하기 전에 매장에 직접 확인해 주세요.

### 로그인 실패

**제목:** 카카오 로그인을 완료하지 못했어요

**설명:** 계정이나 비밀번호의 원인을 추측하지 않는다. `잠시 후 다시 시도해 주세요. 계속되면 아래 요청 번호와 함께 문의해 주세요.`

**행동:** 다시 로그인 · 처음으로

요청 ID는 비민감 난수만 표시하며 provider token이나 Kakao account ID를 포함하지 않는다.

## 3. 위치 안내와 권한

### 서비스 선택 동의 카드

**제목:** 현재 위치로 이동시간을 계산할까요?

**본문:** 현재 위치는 가까운 빵집과 이동 경로를 계산하는 동안만 사용합니다. 경로 계산을 위해 출발 좌표가 Kakao에 전송될 수 있지만, 빵찾깅 계정·대화·분석·로그에는 저장하지 않습니다. 동의하지 않아도 역·동·구를 직접 입력해 이용할 수 있습니다.

**주 행동:** 현재 위치 사용

**대체 행동:** 출발지 직접 입력

위 카드에서 동의한 뒤에만 브라우저의 위치 권한 팝업을 연다. 카카오싱크 약관 동의만으로 현재 위치가 허용됐다고 표시하지 않는다.

### 브라우저 권한 거부

**제목:** 현재 위치를 사용할 수 없어요

**설명:** 브라우저에서 위치가 허용되지 않았습니다. 역·동·구를 입력하면 같은 방식으로 추천을 계속할 수 있어요.

**행동:** 출발지 입력 · 권한 설정 방법 보기

### 시간 초과·정확도 부족

5초 안에 유효 위치를 얻지 못하면 로딩을 끝내고 직접 입력을 제시한다. 낮은 정확도의 좌표로 사용자를 다른 동네에 있는 것처럼 단정하지 않는다.

### 전경 갱신

**상태 배지:** 현재 위치 사용 중

**보조 문구:** 앱을 보고 있는 동안 위치가 갱신됩니다. 100m 이상 이동하거나 새로 계산을 누르면 경로가 바뀔 수 있어요.

**행동:** 위치 사용 중지 · 현재 위치로 새로 계산

## 4. 새 대화와 의도 분석

### 빈 대화

**입력 안내:** 원하는 빵, 맛이나 식감, 피하고 싶은 것과 오늘 갈 수 있는 범위를 자유롭게 말해 주세요.

**예시:** `초콜릿은 빼고 상큼한 과일 데니시를 지금 위치에서 30분 안으로 찾아줘.`

다른 대화의 취향을 먼저 보여주지 않는다.

### 분석 중

**상태:** 원하는 빵과 방문 조건을 정리하고 있어요

분석이 길어져도 `곧 추천됩니다`처럼 완료를 보장하지 않는다. 취소하면 마지막으로 저장된 대화 상태를 유지한다.

### 조건 요약

조건은 네 묶음으로 표시한다.

- 원해요
- 덜 선호해요
- 반드시 빼 주세요
- 오늘의 방문 조건

각 칩은 제거·수정 가능하고 변경 결과를 접근 가능한 상태 메시지로 알린다.

### 확인 질문

**예시:** `초콜릿은 완전히 제외할까요, 관련도만 낮출까요?`

한 추천 시도에서 시스템이 세 번째 질문을 만들면 표시하지 않는다. 대신 현재 해석과 `조건 직접 수정`을 제공한다.

### 의료·알레르기 입력

**제목:** 안전 여부는 추천할 수 없어요

**본문:** 빵찾깅은 재료의 실제 사용 여부나 교차접촉을 검증하지 않습니다. 해당 정보는 추천 조건이나 안전 판정에 사용하지 않으며, 주문 전에 매장에 직접 확인해 주세요. 맛과 식감, 메뉴 조건으로는 계속 찾아드릴 수 있어요.

`안전한 매장`, `먹어도 되는 빵` 같은 표현을 사용하지 않는다.

## 5. 추천 결과

### 성공

**요약:** 현재 조건에서 추천 가능한 빵집을 찾았어요

결과 수, 적용한 정렬과 출발지의 거친 표시를 제공한다. 숫자형 추천 점수는 표시하지 않는다.

### 카드 필수 정보

- 매장명과 대표 매칭 메뉴
- 사실 근거 기반 추천 이유 최대 2개
- 데이터 부족·오래됨·직선거리 여부 등 주의점 최대 1개
- 현재 위치 또는 직접 입력 출발지 기준 이동시간·거리
- 마지막 검수 시각

### 정렬 제어

- `이동시간순`: 기본
- `관련도순`: 현재 대화 조건과 특징 근거 중심

**상태 알림 예:** 관련도순으로 결과를 다시 정렬했습니다. 첫 번째 후보가 변경되었습니다.

### 부분 성공

지도만 실패하면 목록과 주소를 유지한다. 설명 LLM만 실패하면 순위와 카드 기본 정보를 유지하고 템플릿 이유를 보여준다. 경로만 실패하면 이동시간 자리에 `계산할 수 없음`을 표시하고 거리·주소를 유지한다.

## 6. 빈 결과

**제목:** 현재 조건과 데이터에서는 추천 가능한 후보를 찾지 못했어요

**설명:** `빵집이 없어요`라고 단정하지 않는다. 범위, 영업 상태, 강한 제외, 시간·예산 등 단계별 제거 건수를 보여준다.

회복 행동은 다음 순서로 제안한다.

1. 이동 범위를 한 단계 넓히기
2. 예산을 꼭 맞춰야 하는 조건에서 선호 조건으로 바꾸기
3. 특정 시각 영업 조건 풀기
4. 원하는 빵의 인접 카테고리까지 보기

프랜차이즈·폐업·서울 범위·사용자가 지정한 강한 제외는 자동 완화하지 않는다. 의료 조건은 애초에 추천 필터로 사용하지 않는다.

## 7. 외부 장애와 대체 문구

| 상황 | 제목 | 유지하는 것 | 다음 행동 |
|---|---|---|---|
| LLM 의도 분석 실패 | 조건을 자동으로 정리하지 못했어요 | 사용자 메시지 | 조건 직접 선택 · 다시 시도 |
| LLM 설명 실패 | 추천 이유를 간단히 표시했어요 | 순위·근거·매장 정보 | 템플릿 설명 사용 |
| Kakao 지도 실패 | 지도를 불러오지 못했어요 | 목록·주소·거리 | 다시 시도 · 목록 계속 보기 |
| Kakao 경로 실패 | 이동시간을 계산하지 못했어요 | 후보·직선거리·주소 | 다시 계산 · 카카오맵에서 열기 |
| `app_db` 실패 | 추천 데이터를 확인할 수 없어요 | 없음 | 관리자 상태 확인 후 재시도 |
| `raw_db` 실패 | 리뷰 특징 갱신을 멈췄어요 | 기존 구조화 추천 | 관리자만 원인 확인 |
| 원장 7일 초과 | 매장 정보가 평소보다 오래됐어요 | 결과 | 기준일 표시 |
| 원장 30일 초과 | 최신 영업 상태를 확인할 수 없어 새 추천을 멈췄어요 | 과거 대화 | 동기화 후 재시도 |
| 비용 상한 | 자동 설명을 잠시 쉬고 있어요 | 결정론적 추천 | 템플릿·조건 폼 사용 |

경로 실패 시 이전 이동시간이나 직선거리로 시간을 추정해 표시하지 않는다.

## 8. 과거 대화

### 목록

**빈 상태:** 아직 저장된 대화가 없어요. 먹고 싶은 빵을 말하며 첫 대화를 시작해 보세요.

**행동:** 새 대화

목록 미리보기에는 정확 위치, 의료 표현과 긴 메시지 원문을 노출하지 않는다.

### 과거 결과

**배지:** 2026-07-22 14:30에 만든 추천

**안내:** 이 결과는 당시 데이터와 조건으로 만들었습니다. 현재 위치와 이동시간은 다시 계산할 수 있어요.

**행동:** 대화 이어가기 · 현재 위치로 새로 계산 · 이 조건으로 새 대화 시작

### 조건 복사

**확인:** 원하는 빵과 제외·방문 조건만 새 대화에 복사합니다. 메시지, 추천 결과와 정확 위치는 복사하지 않습니다.

## 9. 삭제

### 대화 삭제

**제목:** 이 대화를 삭제할까요?

**본문:** 메시지, 정리된 조건, 추천 결과와 이 대화에 연결된 피드백이 함께 삭제됩니다. 즐겨찾기는 유지됩니다. 삭제한 대화는 복구할 수 없습니다.

**행동:** 대화 삭제 · 취소

### 회원탈퇴

**제목:** 빵찾깅 계정을 삭제할까요?

**본문:** 모든 대화, 추천 결과, 즐겨찾기, 피드백과 로그인 세션을 삭제하고 카카오 연결 해제를 요청합니다. 서비스 데이터는 복구할 수 없습니다.

**행동:** 계정 삭제 · 취소

## 10. 분석 이벤트 허용 범위

UI는 상태 측정을 위해 이벤트 이름, 성공 여부, 비민감 오류 코드, 소요 시간과 결과 개수만 보낼 수 있다. 다음 값은 금지한다.

- 메시지와 조건 원문
- 정확한 위도·경도와 상세 주소
- 카카오 provider account ID와 토큰
- 건강·알레르기 관련 표현
- 리뷰 원문과 프롬프트 전문
