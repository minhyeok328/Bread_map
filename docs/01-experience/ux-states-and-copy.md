# 화면 상태와 카피

[문서 허브](../README.md) · [PRD](../00-product/prd.md) · [사용자 여정](user-journey.md) · [보안 설계](../06-trust/security-design.md)

이 문서는 현재 로컬 MVP에서 사용자가 보는 상태 전이와 공식 한국어 문구의 의미를 정의한다. 실제 UI 문장은 접근성·레이아웃 검토에서 길이를 다듬을 수 있지만 목적·외부 전송·비저장·대체 수단과 안전 한계는 삭제할 수 없다.

## 1. 공통 상태 모델

모든 비동기 화면은 다음 상태를 구분한다.

| 상태 | 요구사항 |
|---|---|
| `idle` | 다음 행동과 현재 조건이 분명하다. |
| `loading` | 100ms 이내 진행 대상과 취소 가능 여부를 알린다. |
| `success` | 완료된 내용과 다음 행동을 알린다. |
| `partial` | 사용 가능한 결과와 실패한 부분을 분리한다. |
| `empty` | 데이터 범위와 제거 이유를 설명하고 회복 행동을 제공한다. |
| `error` | 가짜 결과 없이 재시도와 대체 경로를 제공한다. |
| `stale` | 기준 시각과 신뢰 저하 또는 차단 이유를 표시한다. |
| `confirming` | 삭제·외부 전송처럼 되돌리기 어려운 범위를 명시한다. |

## 2. 시작과 로그인

### 기본

**제목:** 오늘 찾고 싶은 빵이 있나요?

**설명:** 지역·가게·메뉴·카테고리와 방문 조건으로 서울의 검수된 베이커리를 찾아보세요.

**버튼:** 카카오로 시작하기

**안전 고지:** 빵찾깅은 빵집 추천 서비스입니다. 재료·알레르기·교차접촉 정보는 검증하지 않으며 안전을 보장하지 않습니다. 주문하거나 방문하기 전에 매장에 직접 확인해 주세요.

### Kakao OAuth 실패

**제목:** 카카오 로그인을 완료하지 못했어요

**설명:** 잠시 후 다시 시도해 주세요. 계속되면 아래 요청 번호와 함께 확인해 주세요.

**행동:** 다시 로그인 · 처음으로

요청 ID는 비민감 난수만 표시하고 provider token이나 Kakao account ID를 포함하지 않는다.

## 3. 위치와 지역

### 위치 선택 동의

**제목:** 현재 위치를 검색 기준으로 사용할까요?

**본문:** 현재 위치는 가까운 빵집과 거리를 계산하는 현재 요청에서만 사용합니다. 지도 표시를 위해 좌표가 Kakao에 전송될 수 있지만 빵찾깅 계정·검색 기록·분석·로그에는 저장하지 않습니다. 동의하지 않아도 구·동·역을 직접 입력할 수 있습니다.

**주 행동:** 현재 위치 사용

**대체 행동:** 지역 직접 입력

서비스 안내에서 동의한 뒤에만 브라우저 위치 권한을 요청한다. Kakao Login만으로 위치가 허용됐다고 표현하지 않는다.

### 권한 거부·시간 초과·정확도 부족

**제목:** 현재 위치를 사용할 수 없어요

**설명:** 구·동·역을 입력하면 같은 검색을 계속할 수 있어요.

**행동:** 지역 입력 · 권한 설정 방법 보기

유효 위치를 얻지 못하면 로딩을 끝내고 직접 입력을 제공한다. 낮은 정확도 좌표로 사용자의 동네를 단정하지 않는다.

## 4. 구조화 검색

### 초기 상태

**검색 안내:** 지역, 가게, 메뉴 또는 카테고리를 입력해 보세요.

**필터:** 현재 영업 중 · 거리 · 리뷰 근거 상태

입력되지 않은 필드를 추측하거나 다른 검색 기록에서 자동 상속하지 않는다.

### 정규화 중

**상태:** 검색 조건을 확인하고 있어요

지역·가게·메뉴·카테고리의 허용된 값과 빈 값을 정규화한다. 완료를 보장하는 표현을 사용하지 않는다.

### 검색·필터 적용 중

**상태:** 조건에 맞는 빵집을 찾고 있어요

**보조 설명:** 적격성·강한 제외를 먼저 확인한 뒤 메뉴와 리뷰 근거를 비교합니다.

### FTS5 검색 대체

**검색 대체:** 리뷰 검색을 사용할 수 없어 메뉴·카테고리·지역 조건으로 결과를 표시합니다.

이 상태에서는 리뷰가 검색 근거로 사용된 것처럼 표현하지 않는다.

### 의료·알레르기 표현

**제목:** 안전 여부는 추천할 수 없어요

**본문:** 빵찾깅은 재료의 실제 사용 여부나 교차접촉을 검증하지 않습니다. 안전 조건으로 사용하지 않으며 주문 전에 매장에 직접 확인해 주세요. 메뉴와 방문 조건으로는 계속 찾을 수 있어요.

`안전한 매장`, `먹어도 되는 빵` 같은 표현을 사용하지 않는다.

## 5. 지도·목록 결과

### 성공

**요약:** 현재 조건에서 확인된 빵집을 찾았어요

결과 수, 적용 필터, 정렬과 거친 지역을 제공한다. 숫자형 추천 총점은 표시하지 않는다.

### 카드 필수 정보

- 매장명과 대표 메뉴
- 메뉴·카테고리 또는 비식별 리뷰 근거
- 리뷰 충분·부족·오래됨 상태
- 영업·거리와 데이터 기준일
- 데이터 한계 또는 주의점

### 리뷰 부족

**리뷰 부족:** 최근 리뷰 근거가 부족해 확인된 메뉴와 방문 조건을 중심으로 표시합니다.

리뷰가 3개 미만이라는 이유로 적격 매장을 숨기지 않는다. 별점은 핵심 추천 이유로 사용하지 않는다.

### 지도 부분 실패

**제목:** 지도를 불러오지 못했어요

**설명:** 가게 목록과 주소는 계속 볼 수 있어요.

**행동:** 지도 다시 시도 · 목록 계속 보기

지도 실패 시 목록·주소·거리와 매장 상세를 유지한다.

## 6. 빈 결과

**제목:** 현재 조건과 데이터에서는 확인된 후보를 찾지 못했어요

`이 지역에 빵집이 없어요`라고 단정하지 않는다. 지역, 영업, 거리, 강한 제외와 데이터 상태의 단계별 제거 수를 보여준다.

사용자가 선택할 수 있는 회복 행동:

1. 지역 또는 거리 범위를 한 단계 넓히기
2. 현재 영업 중 필터 해제
3. 리뷰 근거 부족 매장 포함
4. 인접한 메뉴 카테고리 보기

프랜차이즈·폐업·서울 범위·관리자 차단과 사용자가 지정한 강한 제외는 자동 완화하지 않는다.

## 7. 매장 상세와 리뷰

### 상세 로딩

**상태:** 가게 정보와 근거를 불러오고 있어요

메뉴와 리뷰를 독립적으로 불러올 수 있다. 한 영역 실패 때문에 검증된 다른 정보를 숨기지 않는다.

### 리뷰 없음

**제목:** 표시할 수 있는 최근 리뷰가 아직 없어요

**설명:** 확인된 메뉴·영업 정보와 데이터 기준일은 계속 볼 수 있어요.

### 오래된 데이터

**배지:** 정보 확인 필요

**설명:** 마지막 검수일을 표시한다. 원장 30일 초과로 새 검색이 차단된 경우 과거 값을 현재 사실처럼 보여주지 않는다.

## 8. SQLite 서비스 데이터 상태

| 상황 | 제목 | 유지하는 것 | 다음 행동 |
|---|---|---|---|
| `app.sqlite` 읽기 실패 | 검색 데이터를 확인할 수 없어요 | 검색 조건 | 로컬 상태 확인 후 재시도 |
| FTS5 색인 불일치 | 리뷰 검색을 사용할 수 없어요 | 메뉴·카테고리·지역 결과 | 대체 결과 보기 · 관리자 점검 |
| `raw.sqlite` 작업 실패 | 리뷰 갱신을 멈췄어요 | 기존 `app.sqlite` 검색·상세 | 관리자만 원인 확인 |
| 원장 7일 초과 | 매장 정보가 평소보다 오래됐어요 | 결과 | 기준일 확인 |
| 원장 30일 초과 | 최신 영업 상태를 확인할 수 없어 새 검색을 멈췄어요 | 검색 조건 | 원장 동기화 후 재시도 |
| snapshot 복구 중 | 저장된 검색 데이터를 복구하고 있어요 | 없음 | 복구 완료 후 무결성 확인 |

`raw.sqlite` 경로·암호화 키·원문은 사용자 오류에 표시하지 않는다.

## 9. 즐겨찾기와 검색/선택 기록

### 빈 기록

**제목:** 아직 저장된 검색 기록이 없어요

**설명:** 검색하거나 가게를 열면 계정에 필요한 최소 기록만 남길 수 있어요.

검색 기록을 `대화 기록`이라고 부르지 않는다.

### 즐겨찾기 변경

**추가:** 즐겨찾기에 저장했어요

**제거:** 즐겨찾기에서 삭제했어요

계정 소유권 검증 실패를 `존재하지 않음` 또는 권한 오류로 처리하고 다른 사용자 존재 여부를 노출하지 않는다.

### 기록 삭제

**제목:** 이 기록을 삭제할까요?

**본문:** 선택한 검색 또는 가게 선택 기록만 삭제합니다. 즐겨찾기와 다른 기록은 유지됩니다.

**행동:** 기록 삭제 · 취소

## 10. 빵빵이 비활성 채팅 셸

**제목:** 빵빵이

**채팅 준비 중:** 챗봇 기능은 다음 단계에서 제공할 예정이에요.

**보조 설명:** 지금은 지도와 가게 검색을 이용해 주세요.

- 입력창과 제안 버튼은 비활성화한다.
- 입력 가능하다고 오해할 placeholder나 전송 버튼을 활성 상태로 표시하지 않는다.
- 메시지 제출, 대화 저장과 network 요청을 만들지 않는다.
- 가짜 AI 답변이나 가짜 리뷰 근거를 표시하지 않는다.

## 11. 회원탈퇴

**제목:** 빵찾깅 계정을 삭제할까요?

**본문:** 즐겨찾기, 검색/선택 기록과 로그인 세션을 삭제하고 Kakao 연결 해제를 요청합니다. 서비스 데이터는 복구할 수 없습니다.

**행동:** 계정 삭제 · 취소

## 12. 분석 이벤트 허용 범위

UI는 이벤트 이름, 성공 여부, 비민감 오류 코드, 소요 시간, 결과 수와 허용된 필터 enum만 기록할 수 있다. 다음 값은 금지한다.

- 검색어·메시지·조건 원문
- 정확한 위도·경도와 상세 주소
- Kakao provider account ID와 token
- 건강·알레르기 관련 표현
- 리뷰 본문·닉네임·fingerprint
- SQLite 파일 경로, prompt와 비밀

## 13. 후속 챗봇 상태

다음 상태와 카피는 현재 화면에 연결하지 않는다.

- 자연어 의도 분석과 `ConversationIntentV2` 검증
- 확인 질문과 네 의도 범주
- 멀티턴 수정·대화 재개·조건 복사
- LLM 분석·설명 실패와 결정론적 템플릿
- OpenAI 비용 상한과 kill switch

후속 Feature는 실제 provider, 개인정보·비용 승인과 함께 상태 문구를 다시 검증한다.
