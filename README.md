# 빵찾깅 (Bread Map)

빵찾깅은 사용자의 빵 취향과 방문 조건을 바탕으로 서울의 독립 베이커리를 추천하는 웹 애플리케이션입니다. 자연어나 선택형 입력으로 원하는 맛과 식감, 메뉴, 거리 등의 조건을 받아 적합한 매장을 찾고 추천 이유와 지도 정보를 함께 제공합니다.

현재는 로컬 MVP를 위한 기획 및 데이터 설계 단계입니다. 추천 대상은 영업 중인 서울 독립 베이커리와 검수된 소규모 직영 브랜드로 제한하며, 후보 선정과 점수 계산은 재현 가능한 규칙을 사용합니다.

## 주요 기능

- 자연어 및 선택형 빵 취향 입력
- 위치와 방문 조건을 반영한 베이커리 추천
- 추천 이유와 취향 적합도 제공
- 매장 상세 정보, 지도, 길찾기 연결
- 즐겨찾기와 방문 피드백 관리
- 공공데이터 기반 매장 검수 및 운영 관리
