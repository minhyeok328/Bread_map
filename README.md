# 빵찾깅 (Bread Map)

빵찾깅은 먹고 싶은 빵의 메뉴·맛·식감과 오늘의 방문 조건을 자연어로 말하면, 서울의 독립 베이커리 후보를 지도와 목록으로 추천하는 웹 애플리케이션입니다.

현재 단계는 카카오 계정 기반 **5인 비공개 MVP**의 제품·데이터 설계입니다. 추천 대상은 영업 중인 서울 독립 베이커리와 검수된 소규모 직영 브랜드로 제한합니다. 추천 후보와 순서는 재현 가능한 규칙으로 결정하며, 화면에는 숫자 점수 대신 추천 이유·이동시간·거리·주의점을 보여줍니다.

## 주요 기능

- 카카오싱크 로그인과 계정별 대화 기록
- 자연어 중심의 전체 세션 멀티턴 탐색
- 강한 제외 조건을 우선 적용하는 결정론적 추천
- 이동시간순·관련도순 목록과 전체 후보 지도
- 현재 위치 기반 경로 비교와 직접 출발지 대체 입력
- 과거 대화·추천 결과·즐겨찾기·피드백 관리
- 공공데이터 기반 매장 검수와 관리자 운영 도구
